Descripción del proyecto

El proyecto consiste en una página web sencilla creada con HTML. A lo largo de la práctica se han incorporado distintas mejoras utilizando ramas independientes y fusionándolas posteriormente en la rama principal (main).

Instalación

Para obtener el proyecto, clona el repositorio:

git clone https://github.com/LidiaTorres-Code/proyecto-git-dam.git

Después, abre el archivo index.html en un navegador web.

Estructura del proyecto

index.html: contiene la estructura y el contenido de la página web.

.gitignore: indica los archivos y carpetas que Git debe ignorar.

Mejoras implementadas

Menú de navegación: se ha añadido un menú con enlaces a las secciones Inicio, Sobre el proyecto y Contacto.

Formulario de contacto: se han incorporado campos para introducir el nombre, el correo electrónico y un mensaje, junto con un botón de envío.
